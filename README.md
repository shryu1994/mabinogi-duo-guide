# 크롬 바스 일반 · 닼메 + 세바 2인 가이드

마비노기 크롬 바스 일반(100)을 다크메이지 + 세인트 바드 둘이서 돌 때 폰으로 넘겨 보는 카드형 가이드다.

## 쓰는 법

- **넘기기**: 좌우로 밀거나 아래 ‹ › 버튼, 위쪽 단계 칩을 누른다. PC에서는 ← → 키.
- **체크**: 항목을 누르면 완료 표시. 판이 끝나면 위의 **새 판**으로 지운다.
- **타이머**: 항목 옆 `⏱ 시작` 또는 아래 ⏱ 버튼. 지속이 끝나면 쿨을 센다. 끝날 때 아래 막대가 빨갛게 깜빡이고, 켜 두면 진동·소리가 난다. 아래 막대의 타이머를 누르면 다시 시작한다.
- **설정**: 가진 펫·스킬, 펫 디버프 담당, 큰 카드를 쓸 그로기(80/90)를 고르면 카드 내용이 바뀐다.
- **화면 유지**: 게임하는 동안 폰 화면이 꺼지지 않게 한다(지원하는 브라우저만).
- **실측 메모**: 근거가 없는 수치를 직접 재서 적는 칸. **메모 복사**로 한 번에 복사된다.
- 체크·타이머·설정·메모는 그 기기 브라우저에만 저장된다.

## 근거 표시

| 표시 | 뜻 |
|---|---|
| 확실 | 공식 공지 |
| 높음 | 나무위키·여러 공략이 일치 |
| 추측 | 이 가이드의 운용안이거나 글 하나뿐 |
| 실측 | 근거가 없어 직접 재야 함 |

카드 아래 **근거** 를 펼치면 출처 링크가 나온다.

## 고치는 법

내용은 전부 `assets/data.js` 한 파일에 있다. 문장·등급·타이머 시간을 고치고 커밋하면 GitHub Pages가 다시 배포한다.

## 한계

- 화면이 꺼지거나 다른 앱이 앞에 있으면 진동·소리 알림이 오지 않는다. 시간 계산은 이어지므로 돌아오면 남은 시간이 맞게 보인다.
- 게임 패치로 수치가 바뀔 수 있다. 기준일은 페이지 제목 옆 날짜다.
- 버그·비정상 우회 방법은 넣지 않는다.

넥슨·마비노기와 관계없는 개인 정리본이다.
